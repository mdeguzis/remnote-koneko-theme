Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), versioning

## [0.1.0] - 2026-08-16

First build.

### Added

- Original pastel cat artwork with shark, bunny and bread costumes, drawn as
  full colour SVG templates that follow the active palette
- Four shades, each with a light and a dark palette: Samecat, Ichigo, Matcha, Purin
- Optional yarn chase across the bottom, with a configurable interval and speed,
  off by default and still under reduced motion
- Panel opacity control, driving `--current-background-color`
- Show debug info command, opening a copyable report of the options in effect
  and the CSS variables actually emitted
